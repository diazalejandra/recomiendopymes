# Requerimientos del Sistema

Esta carpeta almacena la definición funcional del proyecto. Aquí se detallan los módulos principales, sus reglas de negocio y los flujos esperados por el usuario.

## Módulos Actuales (Ejemplo de Estructura)

- **Auth & Usuarios**: Manejo de registro, login, recuperación de contraseñas y roles (Admin, Emprendedor, Visitante).
- **Catálogo & Emprendimientos**: Flujos de creación de fichas de negocio, moderación, y presentación en cuadrícula/mapa.
- **Noticias & Blog**: Gestión de contenidos informativos para los usuarios.

*Recomendación: Crea un archivo `.md` por cada gran módulo o épica (ej. `01-catalogo.md`, `02-auth.md`) para mantener el orden.*
